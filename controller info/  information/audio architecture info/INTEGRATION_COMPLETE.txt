Index 17: "freqbands"    - FrequencyBandVisualizer

          Uses palette: YES (default "rainbow")
          
Index 18: "basspulse"    - BassPulseFunction  
          Full strip pulses with bass frequencies
          Uses palette: NO (solid color, default Blue)
          
Index 19: "spectrum"     - SpectrumAnalyzer
          Classic 20-band spectrum analyzer
          Uses palette: NO (classic green/yellow/red gradient)
          
Index 20: "beatdetect"   - BeatDetector
          Detects beats and creates flash effects
          Uses palette: YES (default "lava")
          
Index 21: "vocals"       - VocalHighlighter
          Highlights vocal frequencies (200-2000 Hz)
          Uses palette: NO (solid color, default Cyan)

═══════════════════════════════════════════════════════════════════════════

CPU Usage (per function when active):
  freqbands:   ~0.4% (band lookups + palette)
  basspulse:   ~0.3% (single band + simple math)
  spectrum:    ~0.6% (20 bands + peak tracking)
  beatdetect:  ~0.5% (history tracking + detection)
  vocals:      ~0.4% (band range + spread calculation)
  
Total if all 5 active: ~2.2% CPU

Memory Usage (per function):
  freqbands:   ~280 bytes (4 band levels + state)
  basspulse:   ~160 bytes (state variables)
  spectrum:    ~900 bytes (20 bands * 3 arrays + state)
  beatdetect:  ~340 bytes (40 history values + state)
  vocals:      ~650 bytes (128 brightness array + state)
  
Total: ~2.3 KB RAM

All functions use SHARED AudioSystem FFT data (no extra audio overhead!)
